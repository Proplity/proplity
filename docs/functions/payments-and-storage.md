## `lib/storage/` — files

Every uploaded file is a `StoredFile` row served by the gateway `GET /api/v1/files/[id]`, which decides
who may read it and reads from the provider recorded on that row (ADR-0010). The provider is chosen
**explicitly** by `STORAGE_PROVIDER` (default `cloudinary`): there is no credential auto-detection and no
silent fallback, an unknown name throws, and `local` is refused in production.
