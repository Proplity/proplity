# Client functions (hooks, contexts, browser `lib/`)

Everything a component calls. Screens read through hooks and write through `useApiSubmit` or the
typed `api.*` client; they do not call `fetch` themselves.

## `hooks/`

## `context/`

| File                    | Exports                                             | Description                                                                                                                                                                                                                                                                            |
| :---------------------- | :-------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AuthContext.tsx`       | `AuthProvider`, `useAuth`, `User`, `UserRole`       | The session in the browser: `user`, `loading`, `login`, `register`, `logout`, `refreshUser`. Seeded from the server session in the root layout; on load it calls `/me` and, if that fails, tries `/auth/refresh` before clearing the user. Roles are lowercased here (`normalizeUser`) |
| `FileViewerContext.tsx` | `FileViewerProvider`, `useFileViewer`, `ViewerFile` | Opens the global file viewer: `openFile(file)` and `openGallery(files, index)`                                                                                                                                                                                                         |

## Browser-side `lib/`

| File                        | Exports                                                                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :-------------------------- | :------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/apiClient.ts`          | `apiClient`, `apiFetch`, `api`, `UploadPlan`                                          | An Axios instance with a **401 interceptor** (one shared refresh, then retry) and the typed `api.*` client grouped by domain: `properties`, `maintenance`, `leases`, `invoices`, `payments`, `bankTransfers`, `bankAccounts`, `vendorPayouts`, `accessCodes`, `conversations`, `notifications`, `applications`, `managerCodes`, `adCampaigns`, `subscriptions`, `uploads`, `dashboard`, `settings`, `vendors`, `admin`. When a refresh fails it sends the tab to `/login` **only if the person is still on the page that asked** (`sendToLogin`; ISS-132) |
| `lib/api/types.ts`          | the request and response types                                                        | Types shared by the client and the routes (`PlatformSettings`, `PaymentRules`, `Property`, `Lease`, `Invoice`, `MaintenanceRequest`, the `Create…Input` types and more). Lowercase roles and statuses as the API returns them                                                                                                                                                                                                                                                                                                                             |
| `lib/uploadClient.ts`       | `uploadFile`, `uploadsEnabled`, `UploadedFile`                                        | The only way to upload: asks `POST /api/v1/uploads/sign` for a plan, sends the file straight to the provider (or through the server), completes it, and returns the file-gateway URL `/api/v1/files/<id>`. `uploadsEnabled()` (Cloudinary cloud name or `NEXT_PUBLIC_STORAGE_ENABLED`) lets the UI show "not available" instead of a dead button                                                                                                                                                                                                          |
| `lib/fileRef.ts`            | `fileUrl`, `parseFileUrl`, `accessForFolder`, `FOLDER_ACCESS`, `UploadFolder`         | Client-safe description of uploaded files and which folders are public or private                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `lib/safeRedirect.ts`       | `safeRedirect`                                                                        | Accepts a `from` or redirect value only if it is a same-origin relative path (rejects `//host`, `https://host`, `/\host`)                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `lib/notificationSound.ts`  | `playNotificationSound`                                                               | A short two-tone chime made with the Web Audio API (no audio file to host); reuses one `AudioContext`                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `lib/utils.ts`              | `fmtNaira`                                                                            | Formats an amount as Naira                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `lib/viewingSlots.ts`       | `VIEWING_TIMES`, `viewingInstant`, `viewingTimeProblem`, `formatViewingTime` and more | Viewing dates and times (Mon to Sat, 9:00 to 17:00 Lagos, half-hour starts), shared by the form and `POST …/viewings` so they cannot disagree                                                                                                                                                                                                                                                                                                                                                                                                             |
| `lib/tenantProfile.ts`      | `isTenantProfileComplete`, `missingTenantProfileFields`                               | The completeness rule that gates a rental application (previous landlord is deliberately not required)                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

| `lib/repairEvidence.ts`     | `MAX_EVIDENCE_PHOTOS`                                                                 | How many before or after photos a repair takes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `lib/receiptTypes.ts`       | `Receipt`                                                                             | The receipt shape the page prints                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `lib/dashboardAttention.ts` | `AttentionItem`, `AttentionSeverity` (types)                                          | The type the attention card reads; the function that builds it is in [`server.md`](./server.md)                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## `app/store/` — illustrative data

Two files of mock data from before the pages were wired to the API, both read only by things that have
no backend: `mockData.ts` by the three marketing feature pages (`TenantFeaturePage`,
`LandlordFeaturePage`, `ServiceProviderFeaturePage`) and `aiAssistantData.ts` by the demo `AIAssistant`.
Nine other files in this folder were imported by nothing and were deleted on 2026-10-20. Do not add new
reads: real screens use the hooks above.
