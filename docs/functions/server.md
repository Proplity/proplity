# Server functions

Server-only helpers (they import `lib/db.ts` or read secrets). The browser-side files are in
[`client.md`](./client.md); payments, files and workers have their own pages.

## Edge guard

| File       | Exports           | Description                                                                                                                                                                                                                                                         |
| :--------- | :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `proxy.ts` | `proxy`, `config` | Next 16's rename of `middleware.ts`. Inspects only the short-lived `access_token` cookie for `/dashboard`, `/admin` and `/receipts`: missing or expired goes to `/?from=…`; a non-admin on `/admin` goes to `/dashboard`; an admin on `/dashboard` goes to `/admin` |

## `lib/api/` — route plumbing

| File                 | Exports                                                                      | Description                                                                                                                                                                                                                                                                                          |
| :------------------- | :--------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `withAuth.ts`        | `withAuth(handler, { roles })`                                               | Wraps a route handler: CSRF check on `POST`/`PUT`/`PATCH`/`DELETE`, the session (401), a fresh read of the user (suspended is 403 at once; the role in the database wins over the token's), then the role check (403). `roles` are uppercase                                                         |
| `validate.ts`        | `validateBody`                                                               | Parses the JSON body with a Zod schema and answers 400 with field errors; refuses a body over 1 MB                                                                                                                                                                                                   |
| `errors.ts`          | `handleApiError`                                                             | Prisma `P2002` is 409, `P2025` is 404, `P2003` is 400; anything else is logged and answered 500                                                                                                                                                                                                      |
| `pagination.ts`      | `parsePagination`, `buildMeta`, `parseCursorPagination`, `buildCursorMeta`   | Page and limit lists, and cursor mode for feeds too long for pages (message history)                                                                                                                                                                                                                 |
| `propertyAccess.ts`  | `canManageProperty`, `serializeUnit`, `PRIVATE_UNIT_FLAG`, `isPrivateUnit`   | `canManageProperty` is true for an admin or the property's own manager or landlord; `serializeUnit` turns the column `squareFeet` into the API's `sqft`; a unit the owner marked "Make Private" carries the amenity `visibility:private` (`PRIVATE_UNIT_FLAG`, the only place that choice is stored) |
| `propertySchemas.ts` | `pendingChangesSchema`, `propertyMetadataSchema` and the staged-edit schemas | Zod schemas for the staged ("pending") edits stored in `Property.metadata`                                                                                                                                                                                                                           |
| `urlField.ts`        | `isSafeUrl`, `safeUrl`, `safeUrlList`, `safeUrlOrName`                       | Accepts a stored URL only if it is an uploaded file's gateway URL or a safe public link, nothing that can run code (ISS-033)                                                                                                                                                                         |
| `messagingAccess.ts` | `checkFreeformParticipants`, `MAX_FREEFORM_PARTICIPANTS`                     | Who may start a direct or support conversation with whom: staff and admins are reachable by any signed-in user; tenants and vendors only by someone who shares a property with them                                                                                                                  |
| `paymentSelect.ts`   | `PUBLIC_PAYMENT_SELECT`                                                      | The only payment fields a screen may receive. The row also holds `rawProviderPayload` (payer email, card data) and a virtual account number, so **never** use `payments: true` or a bare `include`                                                                                                   |
| `fileErrors.ts`      | `handleFileError`                                                            | A `FileError` becomes its HTTP status; anything else goes to `handleApiError`                                                                                                                                                                                                                        |
| `types.ts`           | (types)                                                                      | The API's request and response types, shared with the browser (see [`client.md`](./client.md))                                                                                                                                                                                                       |

## `lib/auth/` — sessions

| File              | Exports                                                                                          | Description                                                                                                                                                                                                                                                                                                |
| :---------------- | :----------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `jwt.ts`          | `signAccessToken`, `verifyToken`, `verifyTokenAllowExpired`, `JWTPayload`                        | The 15-minute access token (`jose`, Edge-compatible). `verifyTokenAllowExpired` accepts a signature-valid but expired token for logout cleanup only, never for authorisation. Throws at load in production without `JWT_SECRET`                                                                            |
| `session.ts`      | `getServerSession`, `getExpiredSession`                                                          | The caller from the `access_token` cookie. `getExpiredSession` is for logout only, which otherwise cannot tell whose refresh tokens to revoke                                                                                                                                                              |
| `cookies.ts`      | `setAuthCookies`, `clearAuthCookies`                                                             | `access_token` (path `/`) and `refresh_token` (path `/api/v1/auth/refresh`), both HttpOnly and SameSite=Lax. A cookie is deleted only with the path it was set with                                                                                                                                        |
| `csrf.ts`         | `validateCSRF`                                                                                   | Origin must match Host, with a `Referer` fallback; denies when both are missing and fails closed on a malformed `Origin`. Not used on `verify-email` and `reset-password` (reached from an email link)                                                                                                     |
| `rateLimit.ts`    | `reserveAttempt`, `releaseAttempt`, `getClientIp`, `REFRESH_MAX_ATTEMPTS`, `registerMaxAttempts` | Database-backed and atomic: `reserveAttempt` takes a Postgres advisory lock for the identifier, counts the window and inserts the reservation in one step, before any slow work; `releaseAttempt` gives it back when an outcome should not count. `getClientIp` returns the **last** `x-forwarded-for` hop |
| `refreshGrace.ts` | `REFRESH_GRACE_MS`                                                                               | How long (10 s) a just-rotated refresh token may be exchanged once more instead of being treated as stolen; read only by `POST /auth/refresh` (ADR-0016, ISS-134).                                                                                                                                         |
| `email.ts`        | `emailSchema`, `findUserByEmail`                                                                 | Emails are lowercased on the way in and looked up case-insensitively. Never `findUnique({ where: { email } })` on user input                                                                                                                                                                               |

## Notifications and email

| File                   | Exports                                                                                                                | Description                                                                                                                                                                                                                                                                                                                                           |
| :--------------------- | :--------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/notifications.ts` | `notifyUser`, `notifyUsers`, `notifyByEmail`, `notifyAndEmail`, `notifyPropertyTeam`, `notifyAdmins`, `tellUnitTenant` | In-app notifications and emails. They never throw, so a failed notification cannot fail the action that caused it. New code uses `notifyAndEmail` (one person), `notifyPropertyTeam`, `notifyAdmins` and `tellUnitTenant`                                                                                                                             |
| `lib/email.ts`         | `sendEmail`, `emailInboxEnabled`, `getRecentEmails`, `clearRecentEmails`                                               | Sends through Resend when `RESEND_API_KEY` is set, otherwise logs. Returns `{ delivered }`: `true` only when Resend accepted the email (a console log or any failure is `false`); `replyTo` sets the Reply-To. With `NEXT_PUBLIC_EMAIL_INBOX_ENABLED` it also keeps recent emails in memory for the dev inbox widget (never on a real deployment)     |
| `lib/contact.ts`       | `contactSchema`, `contactRecipient`, `buildContactEmail`, `messageWentOut`                                             | The contact page's message: the validated shape (message 10 to 5000 characters, a honeypot `website` field), the recipient from `CONTACT_EMAIL`, the email the team receives, and `messageWentOut`, the rule for when the visitor may be told it was sent (delivered, or a console-only message on a developer's machine; never on a real deployment) |
| `lib/appUrl.ts`        | `appUrl`, `getAppUrl`                                                                                                  | The app's own public base URL for links in emails: `NEXT_PUBLIC_APP_URL`, then Vercel's domain variables, then localhost. Never build a link from the request's `Host` (ADR-0005)                                                                                                                                                                     |

## Platform

| File                    | Exports                                  | Description                                                                                                                                                                                                                                                                                                                                                                                                                   |
| :---------------------- | :--------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/db.ts`             | `prisma`                                 | The one Prisma client (the `@prisma/adapter-pg` driver adapter over a `pg` pool), kept on `globalThis` in development. Throws at load in production without `DATABASE_URL`. Never `new PrismaClient()`                                                                                                                                                                                                                        |
| `lib/systemSettings.ts` | `getSystemSettings`                      | Reads the `SystemSettings` singleton (`id = 'global'`), falling back to the schema's defaults when the row does not exist. | `lib/csv.ts`            | `toCsv`, `parseCsv`, `neutraliseFormula` | Small RFC 4180 reader and writer; `neutraliseFormula` prefixes an apostrophe to text that starts with `=`, `+`, `-`, `@` or a tab or return, so an export cannot run as a spreadsheet formula                                                                                                                                                                                                                                 |
| `lib/xlsx.ts`           | `toXlsx`, `parseXlsx`                    | Excel through `exceljs`; reads the first sheet's first row as headers, mirroring `parseCsv`                                                                                                                                                                                                                                                                                                                                   |
