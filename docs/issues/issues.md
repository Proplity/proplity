## Verified during the registration task (2026-10-11)

- A production build with `.env` hardcoding `NEXT_PUBLIC_APP_URL=http://localhost:3099`, served on port 3022, produced `http://localhost:3022/…` links (loopback request origin fallback). A dev server on 3022 did the same. A forged `X-Forwarded-Host` was rejected by the CSRF check (403). → ISS-001 verified.

## Reference material

- `out/certificate_or_file_access/` (git-ignored; written for an LMS certificate product, not Proplity). Not directly applicable (Proplity has logins), but the sections on expiring/single-use tokens, constant-response + rate-limited forms, public verification endpoints and PDF trust map onto ISS-031 (sensitive documents), the e-signed lease PDFs, and the public property "Verified" badge. Re-read before building any document download or public verification feature.

- A sister project's storage notes (`out/certificate_or_file_access/0005-*.md`, `0012-*.md`) describe a multi-provider `StorageDriver` and a key-prefix ownership check; both are now adopted in reduced form (ADR-0008): the owner-prefix check, and a `StorageDriver` interface with Cloudinary as the only implementation (`STORAGE_PROVIDER`). S3/R2/MinIO/Supabase/ImageKit drivers are **not** written.

## Areas still to search (leads, not yet issues)

- RBAC on every route: does a LANDLORD see another landlord's tenants / invoices? (API suite covers main boundaries; sweep the newer routes: `applications`, `bank-accounts`, `admin/audit-logs`, `uploads/sign`.)
- Upload signing: can any role sign any folder? Size/type limits on Cloudinary side.
- Webhook idempotency: replayed `charge.success` creating duplicate payments.
- Timezone handling for due dates and the 02:00 cron (UTC vs Lagos).
- Lease activation concurrency: two managers activating the same unit.
- Invite codes: code enumeration via `GET /manager-codes/check` (public) — rate limited?
- Email deliverability from the production domain (SPF/DKIM) — not yet verified.
- Accessibility: form labels lack `htmlFor` (also why Playwright can't use `getByLabel`).
- Large public assets: `public/` is ~41 MB of screenshots; build and deploy size.
