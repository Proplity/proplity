# Admin pages (`/admin/*`)

`app/admin/layout.tsx` lets only `ADMIN` in (everyone else goes to `/dashboard`) and renders
`AdminChrome`: a sidebar with System Overview, Properties, User Management, Reports, Bank Transfers,
Security and Platform Settings, a slide-over drawer on a phone, and the notification bell.
Components are in [`../components/admin.md`](../components/admin.md).

| Route                     | File                              | Description                                                                                                                                                                                                                                                                                                                               |
| :------------------------ | :-------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/admin`                  | `admin/page.tsx`                  | System Overview: platform totals from the server (`AdminDashboard`); each card opens a breakdown                                                                                                                                                                                                                                          |
| `/admin/breakdown/[type]` | `admin/breakdown/[type]/page.tsx` | The page a card opens: `users`, `properties`, `transactions` or `maintenance`, with server totals and a paged table                                                                                                                                                                                                                       |
| `/admin/properties`       | `admin/properties/page.tsx`       | The moderation queue: every listing as a list or grid, filtered by moderation status (Pending Review, Approved, Rejected, Flagged, Merged or All), a **Duplicate** badge, a review drawer (approve or reject a listing or one of its units, approve a staged edit, unpublish, re-approve, moderation notes) and a merge-duplicates dialog |
| `/admin/properties/[id]`  | `admin/properties/[id]/page.tsx`  | One listing in the same management view the property team sees (`PropertyDetail`)                                                                                                                                                                                                                                                         |
| `/admin/users`            | `admin/users/page.tsx`            | User management as cards or a table: search, role and status filters, a profile panel. Suspending, reactivating or changing a role asks for a reason and is written to the audit log                                                                                                                                                      |
| `/admin/reports`          | `admin/reports/page.tsx`          | Reports and analytics in five tabs: Overview, Financial, Users, Properties and Maintenance, with a month range                                                                                                                                                                                                                            |
| `/admin/payments`         | `admin/payments/page.tsx`         | Every bank transfer on the platform, for confirmation or rejection by someone other than the person who recorded it (`BankTransferReconciliation`)                                                                                                                                                                                        |
| `/admin/security`         | `admin/security/page.tsx`         | The audit log: sensitive actions (suspensions, role changes, manual payments, invoice edits, reconciliations, payouts, retention and storage) with filters and expandable details                                                                                                                                                         |
| `/admin/settings`         | `admin/settings/page.tsx`         | Platform Settings, four switches: auto-complete a repair when the vendor invoices; ask tenants to confirm finished repairs; a tenant's payment recorded by the team needs a second person; a vendor's payment needs a second person                                                                                                       |
| `/admin/notifications`    | `admin/notifications/page.tsx`    | The admin's notification list                                                                                                                                                                                                                                                                                                             |
