What is Proplity?

Proplity is an all-in-one property management platform built for the Nigerian real estate market. Think of it like a digital property office that connects everyone involved in renting a home.

🏠
Tenant
Pays rent, reports repairs, manages lease
🏗
Landlord
Owns properties, tracks revenue
👔
Manager
Runs daily operations for landlords
🔧
Vendor
Fulfils repair and maintenance jobs
🛡

Oversees the entire platform

First-Time Platform Setup
Super Admin Bootstrap — one-time only — done before anyone else can use the platform

0The Setup Page /setup

When Proplity is installed for the very first time, there are no admin accounts at all. The /setup page is a special one-time wizard to create the first "super admin" account. After the first admin is created, this page permanently disables itself for security — it can never be used again.

⚠️
If you navigate to /setup and get redirected to the login page, the platform was already set up. The super admin already exists.
What you see on the setup form
  • Full name field for the first admin account
  • Email address (becomes the admin login email)
  • Password (must be strong — letters, numbers, symbols)
  • A single "Create Admin Account" submit button

Step-by-step setup instructions:

  1. Open http://yourdomain.com/setup (or http://localhost:3000/setup in development)
  2. If the form appears, fill in your Full Name, Email, and a strong Password
  3. Click Create Admin Account
  4. You'll be redirected to the login page automatically
  5. Log in with the email and password you just set
  6. 🎉 You are now inside the Admin Dashboard — setup is complete!
🔐
Security note: This page cannot be accessed again after setup. To reset admin access, a developer must modify the database directly.
