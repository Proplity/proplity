# Dashboard components

Behind the routes in [`../pages/dashboard.md`](../pages/dashboard.md). Files are in
`app/components/` unless a path says otherwise. Components used by every area (dialogs, photo grids,
the attention list, notifications) are in [`shared.md`](./shared.md).

## Shell

| File                                | Description                                                                                                                                                                                                                                                                                                     |
| :---------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/dashboard/DashboardChrome.tsx` | The frame of every `/dashboard/*` page: header (logo, dev role switcher, notification bell, settings, name and avatar, sign out), the role's sidebar (`getTabsForRole`) and, on a phone, the bottom tab bar. Renders no role's tabs until the real role is known, so a reload never flashes another role's menu |
| `app/dashboard/MobileTabBar.tsx`    | Replaces the sidebar below `lg`: the first three tabs directly, the rest in a **More** sheet with Log out. Takes the same tab list as the sidebar (`shortLabel` is the compact label)                                                                                                                           |

## Role dashboards (`/dashboard`)

| File                          | Role                      | Description                                                                                                                                                                                                                                                                                                                                             |
| :---------------------------- | :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Dashboard.tsx`               | manager                   | Totals (properties, active rents, rent collected this month, pending maintenance) from `useOwnerSummary`, recent payments, upcoming renewals, the landlords linked by invite code, and the attention list                                                                                                                                               |
| `LandlordDashboard.tsx`       | landlord                  | Portfolio: property performance, revenue breakdown (rent collected, pending, maintenance costs, net), recent activity, owner actions, **Schedule a Review** (opens a message), manager access codes (issue, enable, disable), a banner to finish setup (bank account), CSV export                                                                       |
| `TenantDashboard.tsx`         | tenant                    | "My Rental Dashboard": quick actions, property and rent information, rent signature, payment information (pay, auto-pay), maintenance requests, guest access codes, documents. The rent button and auto-pay setup say "Card payments are not available yet" until a Paystack key is set (ISS-010)                                                       |
| `VendorDashboard.tsx`         | vendor                    | "My Jobs": job counts, a filterable job list by status and priority, this week, performance and payments                                                                                                                                                                                                                                                |
| `DashboardBreakdownPage.tsx`  | manager, landlord         | The page a card opens (`properties`, `tenants`, `rent`, `maintenance`, `renewals`): server-computed buckets and charts above a paged table                                                                                                                                                                                                              |
| `TeamPanel.tsx`               | manager                   | The company screen at `/dashboard/team`: create the company, the seats meter (people against the plan's users), the member list, **Add a person** (an email to set a password), remove, and **Who manages what** (the partner picks the manager of each property). A member sees the list but none of the controls                                      |
| `PortfolioImport.tsx`         | manager, landlord         | The import screen at `/dashboard/properties/import`: template download, file upload, preview (counts, per-property tables, problems by row, the plan's unit limit, how many invitations can go today), import, then a **Send invitations** button                                                                                                       |
| `RentAgreementCard.tsx`       | manager, landlord, tenant | The rent agreement on a rent's page. The property team: create from a template or upload one they already have, edit or send the draft, withdraw, witness details and the stamp duty tracker. The tenant: read and print it, then sign it (generated) or confirm it with their name (uploaded). A rent with no agreement keeps the plain signature card |
| `WitnessLinks.tsx`            | manager, landlord, tenant | **Witnesses sign by email** on the agreement card: name and email for each side, send / send again / take back, and who has signed. The team sees both sides, the tenant only their own; hidden when the admin switches it off                                                                                                                          |
| `RentSignatureCard.tsx`       | manager, landlord, tenant | The click-wrap signature: a typed full name recorded with the time and address; the rent is fully signed once a tenant and a landlord-side signature exist                                                                                                                                                                                              |
| `AgreementBuilder.tsx`        | manager, landlord         | The agreement form at `/dashboard/tenants/[id]/agreement` with its live preview and the legal warnings of the place                                                                                                                                                                                                                                     |
| `AgreementDocument.tsx`       | all signed-in roles       | The agreement as a document to print, or **Download PDF** (made on the server), at `/agreements/[rentId]`: numbered clauses, special conditions under the landlord's own heading, signatures with their times, witness lines, stamp duty                                                                                                                |
| `ProfileCompletionBanner.tsx` | tenant                    | "Finish your profile" at the top of the tenant dashboard until phone, year of birth, emergency contact and ID are filled in; links to `/dashboard/profile/complete`                                                                                                                                                                                     |
| `BuyCreditsButton.tsx`        | manager, landlord         | Opens the credit packs (name, credits, price) and sends the buyer to the card page; nothing shows while the admin has buying switched off. Used on the plan card and in the agreement form when the balance is below the cost                                                                                                                           |
| `PlanUsageCard.tsx`           | manager, landlord         | The plan, units and users used, extra units and their cost, and credits (with **Buy credits**), on the manager and landlord dashboards. A company member sees the company's figures and no **Change plan** button (only the managing partner can change the plan)                                                                                       |

## Properties (property team)

| File                            | Description                                                                                                                                                                                                                                                                                                         |
| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ListProperty.tsx`              | The list-a-property wizard: property information, units (add or remove cards), media upload (360° video, photos of every room, exterior view), review, then submit for admin review                                                                                                                                 |
| `PropertyDetail.tsx`            | The management page for one property (also the admin's view): listing status and publish, edit details (staged for admin review), announcements, equipment, viewing requests, units and tenants, rental applications, financial summary, recent maintenance, neighbourhood information, merge or unmerge duplicates |
| `PropertyPhotoManager.tsx`      | Add and remove a listing's photos and choose the cover photo, in a dialog                                                                                                                                                                                                                                           |
| `GateCheckCard.tsx`             | For the person at the gate: pick the unit, type the guest's code, see at once whether to let them in (each check is logged; a one-time code is used up when it lets someone in), with the unit's codes below                                                                                                        |
| `AccessCodeCard.tsx`            | One gate code: who it is for, when it ends, its state, **Revoke**, and the log of every check. Used here and on the tenant dashboard                                                                                                                                                                                |
| `NeighbourhoodReportEditor.tsx` | Writes a property's neighbourhood report: rating, status, features and notes for each section, keeping any other keys the section already had (ISS-016)                                                                                                                                                             |
| `NeighbourhoodReport.tsx`       | The tenant's view of the neighbourhood report for their current home: security, electricity and power, road network, flooding, nearby amenities and demographics (a Premium upgrade prompt stands in front of it when subscriptions are on)                                                                         |
| `PropertyDiscovery.tsx`         | Browse published properties with a search box and four filters (All, Verified Only, High Trust Score, New Listings); each card shows the cheapest unit, and the property's own team gets the ad-campaign button                                                                                                     |

## Tenants and rents (property team)

| File                   | Description                                                                                                                                                                                                                                                                                                                                                                                     |
| :--------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TenantManagement.tsx` | The tenant list. A rent has no stored rent status, so due, overdue and paid are derived from its rent invoices (the earliest unpaid one decides)                                                                                                                                                                                                                                                |
| `AddTenantForm.tsx`    | Multi-step form that creates a tenant and a rent on a unit (terms, rent, service charge, grace period and late-fee rule)                                                                                                                                                                                                                                                                        |
| `TenantDetail.tsx`     | The tenancy record: rent signature, rent information, renew, send notice, send invoice, late fee and grace period, payment history, **Record cash or transfer payment** (needs a second person unless an admin turned that off), violations, condition reports, manager notes, maintenance, payment reliability, terminate. Also exports `RentSignatureCard`, which the tenant dashboard reuses |

## Repairs and schedules

| File                            | Roles             | Description                                                                                                                                                                                                                                                                                                    |
| :------------------------------ | :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MaintenanceBoard.tsx`          | manager, landlord | The repair board: repairs in status columns, one, two or three across depending on the screen width, with **Raise a repair**                                                                                                                                                                                   |
| `RaiseRepairForm.tsx`           | manager, landlord | A repair the team raises itself: any unit it looks after, occupied or vacant, with or without a vendor. It has no tenant, so nobody is asked to confirm it                                                                                                                                                     |
| `MaintenanceDetail.tsx`         | manager, landlord | One repair: triage, description, photos and evidence, timeline, assigned vendor (assign, send back, give to another), actions, cost tracking and the vendor's invoice (`InvoicePayments`). The vendor invoice's Pay button becomes "Card payments are not available yet" until a Paystack key is set (ISS-010) |
| `MaintenanceSchedules.tsx`      | manager, landlord | Recurring maintenance: add, pause, resume or remove a schedule (a unit or equipment, a category, a frequency); dates keep their day of the month                                                                                                                                                               |
| `MaintenanceRequestForm.tsx`    | tenant            | Report a repair: category buttons resolved to the real `MaintenanceCategory`, priority, description and photos                                                                                                                                                                                                 |
| `TenantMaintenanceRequests.tsx` | tenant            | The tenant's own requests with their status; **Confirm fixed** or **Still a problem** (with a reason and optional photos) when the work is done                                                                                                                                                                |
| `RepairPhotos.tsx`              | all               | `PhotoGrid` (shows a repair's photos in the viewer) and `PhotoPicker` (chooses and uploads up to the limit). Also in `shared.md`                                                                                                                                                                               |

## Applications, viewings and profile (tenant)

| File                          | Description                                                                                                                                                                                                                                                                                                                         |
| :---------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PropertyApplicationForm.tsx` | The rental application for one unit: employment and income, and move-in details. Identity and vetting data come from the tenant profile, so it asks for little                                                                                                                                                                      |
| `CompleteProfileForm.tsx`     | The one-time tenant profile (identity, year of birth, emergency contact, previous landlord, ID document); `isTenantProfileComplete` gates applications on it                                                                                                                                                                        |
| `ScheduleViewing.tsx`         | Pick a date and a half-hour start time (Lagos time, Mon to Sat) for a viewing; starts from the signed-in person's own details. Reads the day's booked times (`useViewingAvailability`) and marks, lists and disables them; if the time is taken while the form is open, confirming sends the person back to the time step (ISS-104) |
